# Helper function: get groundwater options

Helper function: get groundwater options

## Usage

``` r
get_groundwater_options()
```

## Value

return available groundwater data options and prepare for being used as
input for
[`get_groundwater_data`](https://kwb-r.github.io/wasserportal/reference/get_groundwater_data.md)

## Examples

``` r
get_groundwater_options()
#>   groundwater.level groundwater.quality 
#>               "gws"               "gwq" 
```
