# Helper function: list data to csv or zip

Helper function: list data to csv or zip

## Usage

``` r
list_data_to_csv_or_zip(data_list, file_prefix, to_zip)
```

## Arguments

- data_list:

  data in list form

- file_prefix:

  file prefix

- to_zip:

  whether or not to convert to zip file

## Value

loops through list of data frames and uses list names as filenames
